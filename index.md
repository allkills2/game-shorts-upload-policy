# Game Shorts Upload 개인정보 처리방침

Game Shorts Upload 는 운영자 본인의 유튜브 채널에 영상을 올리는 개인용 도구입니다.

## 사용하는 권한

유튜브 영상 업로드 권한(`youtube.upload`) 하나만 사용합니다.

# Game Shorts Upload Privacy Policy

Game Shorts Upload is a personal tool that uploads videos to the operator's own YouTube channel.

## Permission used

It uses a single permission: YouTube video upload (`youtube.upload`).

## Data collected

It does not collect, store, or share information about any user other than the operator. The authorization credentials obtained through Google sign-in are kept only on the operator's computer and are not sent anywhere else.
